# Cargo Incident App

This Flutter app allows users to record incidents for cargo transport vehicles and drivers. It provides the ability to capture the current GPS location, take a photo of the incident, and attach additional files.

## Features

- Retrieve current device location using the `location` package.
- Capture images from the camera using `image_picker`.
- Attach documents through `file_picker`.
- Basic UI built with Material Design.

To build and run the app, ensure Flutter is installed and run:

```bash
flutter pub get
flutter run
```
